# v1.7.0 -- Live daily summary rollup

## Motivation

Anomaly D (2026-10-07): daily_summary empty after 11 days on prod.
Root cause: db.async_run_maintenance aggregates only cycles older than
cycle_retention_days (365d on prod). It is an archival ledger, not a
live view. Fresh DBs stay empty until one retention window elapses.

Impact: diagnostics section always blank; async_daily_summary() consumers
get []. No user-visible bug. Handoff label was misleading.

## Design

- daily_summary becomes LIVE view of every completed day.
- Full-recompute per day: ON CONFLICT DO UPDATE SET cycles=excluded.cycles.
- 3 triggers: cycle-close (today), 03:00 (yesterday then prune),
  startup backfill (guarded one-time).
- Prune never touches daily_summary (rollup-before-prune refactor).
- New OptionsFlow toggle daily_summary_live_enabled (default True).
- Coordinator triggers wrapped in try/except; never block cycle close.
